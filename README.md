# XMap 用户介绍

XMap（Nebula Map）是一款桌面地图软件，用于浏览在线地图、加载本地矢量数据、选择地图区域，并将指定区域导出为离线影像文件。

它适合需要查看地理位置、叠加业务数据、制作离线底图或保存地图区域的用户使用。

## 可以用 XMap 做什么

- 浏览在线地图。
- 在 2D 平面地图和 3D 地球视图之间切换。
- 打开本地矢量文件并叠加到地图上。
- 切换不同底图源。
- 管理图层显示、隐藏和顺序。
- 框选或绘制多边形选择地图区域。
- 将当前区域导出为 GeoTIFF、PNG 或 JPEG。
- 查看导出任务进度和历史记录。
- 配置网络代理以改善地图加载。
- 在中文和英文界面之间切换。

## 主界面说明

启动 XMap 后，主界面主要由以下区域组成：

| 区域 | 说明 |
| --- | --- |
| 地图视图 | 显示当前地图、矢量图层和选择区域 |
| 顶部菜单 | 打开数据、切换视图、使用工具和设置语言 |
| 工具栏 | 快速打开矢量数据、切换 2D/3D 模式 |
| 图层面板 | 选择底图源，管理已加载图层 |
| 状态栏 | 显示当前坐标、缩放级别、视图模式和加载状态 |

## 浏览地图

打开软件后，地图视图会显示在线底图。可以使用鼠标进行基本操作：

- 拖拽地图：移动视图。
- 滚轮：放大或缩小地图。
- 选择 2D 模式：以平面地图方式查看。
- 选择 3D 模式：以三维地球方式查看。

右侧图层面板顶部可以选择不同的地图源。切换后，地图会自动加载新的底图。

## 切换 2D 和 3D

XMap 支持两种查看方式：

| 模式 | 适用场景 |
| --- | --- |
| 2D 模式 | 查看道路、区域边界、矢量数据和导出范围 |
| 3D 模式 | 从地球视角观察更大范围的空间位置 |

可以通过工具栏上的“2D Mode / 3D Mode”按钮切换，也可以在“视图”菜单中选择对应模式。

## 打开矢量数据

XMap 支持打开常见地理矢量文件：

- `.shp`
- `.kml`
- `.geojson`
- `.json`
- `.gpx`
- `.gpkg`

操作步骤：

1. 点击“文件 -> 打开矢量数据”。
2. 选择要打开的文件。
3. 文件加载完成后，会显示在地图上。
4. 新图层会出现在右侧图层面板中。

如果数据较大，加载可能需要一些时间。加载完成后，状态栏会显示提示信息。

## 管理图层

右侧图层面板用于管理地图和已加载的数据。

可以进行以下操作：

- 切换底图源。
- 勾选或取消勾选图层，控制显示与隐藏。
- 拖拽图层调整顺序。
- 右键图层进行删除、上移或下移。

当加载多个矢量文件时，可以通过图层面板控制每个图层是否显示。

## 选择地图区域

XMap 提供两种区域选择方式：

| 选择方式 | 操作 |
| --- | --- |
| 矩形区域 | 选择工具后，在地图上拖拽形成矩形 |
| 多边形区域 | 选择工具后，依次点击多边形顶点，右键或双击结束 |

相关菜单位于“工具”中：

- 选择矩形区域
- 选择多边形区域
- 清除选中区域

选择区域后，可以用于后续导出。

## 导出地图区域

XMap 可以将当前视图或选中的区域导出为文件。

支持格式：

- GeoTIFF
- PNG
- JPEG

操作步骤：

1. 先选择一个区域；如果没有选择区域，则使用当前地图视图范围。
2. 点击“工具 -> 导出当前区域为 GeoTIFF”。
3. 在导出窗口中选择地图源、缩放级别、输出格式和保存路径。
4. 点击确认开始导出。
5. 在任务窗口中查看下载和导出进度。

导出窗口中常见选项说明：

| 选项 | 说明 |
| --- | --- |
| Source | 选择用于导出的地图源 |
| Zoom range | 设置导出的缩放级别，级别越高越清晰，文件也越大 |
| Concurrency | 同时下载的任务数量 |
| Format | 输出文件格式 |
| Compression | GeoTIFF 压缩方式 |
| Min success ratio | 下载成功率低于该值时，等待用户决定是否继续导出 |
| Output | 保存位置 |

## 查看任务

导出开始后，可以在“工具 -> 任务”中查看任务列表。

任务窗口中可以：

- 查看任务状态。
- 查看进度。
- 暂停或恢复任务。
- 取消任务。
- 重试失败任务。
- 在下载不完整时强制导出。
- 打开输出文件夹。
- 查看任务日志。

如果软件意外关闭，下次启动时可能会提示是否恢复未完成的导出任务。

## 查看下载历史

在“工具 -> 下载历史”中可以查看已完成或失败的导出记录。

历史窗口中可以：

- 查看导出时间、地图源、缩放级别、文件格式和输出路径。
- 打开文件所在文件夹。
- 删除单条历史记录。
- 清空全部历史记录。

## 自定义地图源

如果默认地图源不能满足需求，可以在“工具 -> 管理瓦片源”中添加自定义地图源。

自定义地图源通常需要填写地图名称、地址模板和相关参数。添加后，它会出现在图层面板的底图源列表中。

## 网络代理

如果在线地图加载较慢或无法访问，可以在“工具 -> 网络代理”中配置代理。

支持：

- HTTP 代理
- SOCKS5 代理

启用代理后，瓦片下载会通过设置的代理地址进行访问。

## 语言切换

在“语言”菜单中可以切换：

- 中文
- 英文

切换后，菜单、按钮和窗口标题会更新为对应语言。

## 常见问题

### 地图没有加载出来

可以检查以下内容：

- 当前网络是否可用。
- 地图源是否可访问。
- 是否需要设置网络代理。
- 当前缩放级别是否超出地图源支持范围。

### 矢量文件打开失败

可以检查：

- 文件格式是否受支持。
- Shapefile 相关文件是否完整。
- 文件路径是否包含无法访问的位置。
- 数据坐标系是否有效。

### 导出文件很大

缩放级别越高，导出的瓦片越多，文件也越大。可以降低 Zoom range，或者缩小选择区域。

### 导出时出现缺块

可能原因包括网络异常、地图源限制或部分瓦片不存在。可以尝试重试任务，或在任务窗口中根据实际情况选择强制导出。

## 适用场景

XMap 适用于：

- 日常地图浏览。
- 业务区域快速查看。
- 加载本地矢量边界或路线数据。
- 制作离线地图底图。
- 导出指定区域影像。
- 对比不同在线底图源。

## 使用建议

- 大范围导出时，先使用较低缩放级别估算瓦片数量。
- 高缩放级别适合小范围精细导出。
- 导出前尽量确认地图源可以正常加载。
- 对于重要任务，可以在任务窗口中观察下载进度和失败数量。
- 多个图层叠加时，可以通过隐藏部分图层提升查看清晰度。
